# StockFlow.API

Sistema de estoque para distribuidora de eletrônicos.

---

## Objetivo

Controlar entrada, saída e rastreabilidade de produtos eletrônicos.

---

## Problemas resolvidos

- divergência de estoque
- produtos sem rastreabilidade
- auditoria inexistente
- inventário lento

---

## Funcionalidades

- autenticação JWT
- controle de estoque
- movimentações
- auditoria
- serial number
- fornecedores

---

## Tecnologias

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- JWT
- FluentValidation

---

## Arquitetura

- Clean Architecture
- Repository Pattern
- Services
- DTOs
